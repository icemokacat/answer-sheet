# 객관식 답안지 (Answer Sheet)

## 1. 간단한 소개

객관식 답안지를 화면에서 클릭으로 채점하는 도구입니다.

- 문제 수(1~500), 보기 개수(2~6, ①②③④⑤⑥)를 원하는 대로 설정
- 문제별로 클릭해서 답 기록
- 정답을 입력하면 자동으로 O/X, 점수, 오답 목록 표시
- 입력한 답/정답은 자동 저장되어 새로고침·재실행해도 유지

두 가지 방식 중 편한 대로 쓰면 됩니다.

- **`index.html` 파일 하나**로 브라우저에서 바로 사용 (OS 무관, 설치 불필요)
- **macOS 앱(.dmg)**으로 설치해서 일반 앱처럼 실행 (Mac 전용)

## 2. 이용 방법

### 2.1 HTML 이용법

1. `index.html` 파일을 받는다
2. 더블클릭하거나 브라우저에서 연다 (Chrome, Safari, Edge 등 아무 브라우저나 가능)
3. 문제 수 / 보기 개수를 입력하고 "답안지 생성" 클릭
4. 문제별로 보기를 클릭해서 답을 기록 (자동 저장됨)
5. "정답 입력" 칸에 정답을 입력 (숫자 또는 원문자, 공백/쉼표 등 구분자는 무시됨. 예: `1 3 2 4` 또는 `①③②④`)
6. "채점" 클릭 → 점수와 오답 목록 확인

브라우저의 `localStorage`에 저장되므로, **같은 브라우저**로 다시 열면 이전 상태가 복원됩니다. 브라우저를 바꾸거나 시크릿 모드로 열면 저장된 내용이 보이지 않습니다.

### 2.2 macOS 앱(.dmg)으로 실행하는 방법

> **사용할 파일은 이것 하나입니다**: `dist/AnswerSheet-1.0.0-arm64.dmg`
>
> `npm run dist`를 실행하면 `dist/` 폴더 아래에 두 가지가 생기는데, 둘 다 필요한 게 아니라 **`.dmg` 파일 하나만** 쓰면 됩니다.
> - ✅ `dist/AnswerSheet-1.0.0-arm64.dmg` — 배포/공유용 설치 이미지. **이걸 전달하거나 실행하세요.**
> - ⛔️ `dist/mac-arm64/AnswerSheet.app` — 빌드 중간에 생기는 산출물(위 `.dmg` 안에 들어가는 원본 앱 폴더). 배포용이 아니며, 다시 `npm run dist`를 실행하면 지워졌다 새로 생기는 임시 폴더이므로 신경 쓰지 않아도 됩니다.

1. `dist/AnswerSheet-1.0.0-arm64.dmg` 파일을 받는다
2. 더블클릭해서 마운트한다
3. 안에 있는 `AnswerSheet.app`을 `Applications` 폴더로 드래그한다
4. **최초 실행 시 주의**: 이 앱은 Apple 유료 개발자 인증서로 서명(공증)되지 않았기 때문에, macOS가 "확인되지 않은 개발자" 경고를 띄우며 실행을 막습니다. 아래 방법으로 **최초 1회만** 허용하면 이후에는 평소처럼 더블클릭으로 실행됩니다.
   - `Applications` 폴더에서 앱을 **우클릭(또는 control+클릭) → 열기** → 뜨는 창에서 다시 "열기" 클릭
   - 그래도 안 열리면: **시스템 설정 → 개인정보 보호 및 보안** 하단에 있는 **"그래도 열기"** 버튼 클릭
5. 이후에는 Dock/Launchpad/Finder에서 일반 앱처럼 더블클릭 실행 가능

**주의 (아키텍처)**: 현재 배포된 `.dmg`는 **Apple Silicon(M1/M2/M3 등, arm64) 전용**입니다. Intel Mac에서는 실행되지 않습니다. Intel Mac에서 쓰려면 아래 "3. 직접 빌드하기"를 참고해 해당 기기에서 직접 빌드해야 합니다.

> 검토 결과: `.dmg`를 받은 사람의 Mac에서는 다운로드 시 붙는 격리(quarantine) 표시 때문에 Gatekeeper가 앱을 자동으로 차단합니다(더블클릭만으로는 실행 불가, `spctl` 평가 결과 `rejected`로 확인됨). 위 4번의 "우클릭 → 열기" 절차가 항상 필요합니다 — 이는 버그가 아니라 Apple 개발자 인증서로 서명하지 않은 모든 앱에 공통되는 macOS 동작입니다.

## 3. 직접 빌드하기 (선택)

다른 사람에게 받은 `.dmg`를 못 믿겠거나, Intel Mac용으로 빌드해야 하거나, 코드를 수정해서 쓰고 싶은 경우 직접 빌드할 수 있습니다.

요구사항: [Node.js](https://nodejs.org) 설치

```bash
git clone <이 저장소 주소>
cd answer-sheet
npm install
npm run dist
```

빌드가 끝나면 `dist/` 폴더에 실행 중인 기기의 아키텍처에 맞는 `AnswerSheet.app`과 `.dmg`가 생성됩니다. 빌드 스크립트가 실행에 필요한 서명(ad-hoc 서명 + JIT 엔타이틀먼트)까지 자동으로 처리하므로, `npm run dist` 한 번이면 바로 실행 가능한 앱이 나옵니다.

빌드한 앱도 공증되지 않은 것은 동일하므로, 최초 실행 시 위 2.2의 Gatekeeper 허용 절차가 그대로 필요합니다.

개발 중 바로 실행해보고 싶다면:

```bash
npm start
```

## 4. 폴더 구조

```
answer-sheet/
  index.html          # 브라우저에서 바로 여는 단일 파일 앱
  electron/main.js    # index.html을 로드하는 Electron 진입점
  build/              # macOS 서명 관련 설정 (entitlements, afterSign 훅)
  package.json        # 빌드/실행 스크립트, electron-builder 설정
  dist/                # npm run dist 실행 후 생성되는 빌드 산출물 (git에는 포함 안 됨)
    AnswerSheet-1.0.0-arm64.dmg   # 배포/공유용 — 이것만 사용
    mac-arm64/AnswerSheet.app     # 빌드 중간 산출물 — 배포용 아님, 신경 안 써도 됨
```
